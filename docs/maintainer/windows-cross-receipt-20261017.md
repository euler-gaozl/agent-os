## 修复范围

真实任务的一条引用横跨同一文档的两次相邻阅读（1200–2400、2400–3600），旧核验器只在单条回执内搜索，因此 27 条引用中有一条误报。历史证据的原始文件摘要在 `response.document.metadata.original_hash`，不是 document 顶层。独立评审在实现阶段指出了该字段路径，已修正，并以顶层同名字段作为负例回归。

Runtime `b723081` 只读投影合法的留存 original_hash；其他 metadata 不公开。Futures `f99d4de` / 检查器 v6 仅将同文档、同原文摘要、实际读过且严格相邻的区间拼接，拒绝缺页、不同版本和同版本重叠内容矛盾。每段保留独立操作、回执版本、阅读及引用字符范围；Web 逐段带版本回读后展示，未伪造一份合并阅读回执。

仍按每文档最多八条回执、48 次请求、256 KiB 正文和原有超时处理。不能据此声称已阅读全文或核实来源真实性。旧 Runtime 不提供摘要时仍可单回执匹配，跨回执保持未确认。无数据库迁移、历史数据改写或 Harness/Worker 协议变更。
