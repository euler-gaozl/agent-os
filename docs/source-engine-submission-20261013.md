## 下一步与限制

执行器配置被接受不等于部署组合可用。下一步先完成发布兼容/回滚守卫，校验 Runtime 迁移、source submission/management 协议、Worker 编译时固定的 Harness 清单和至少一个可处理新执行器的实例，再做备份、正式迁移与本机切换。不得先打开默认值把任务留在无人领取的队列。

DSH 全历史内存、原生恢复/重放成本、缓存生命周期仍未闭环。运行详情的既有调用列表仍一次读取全部回执，较长任务需要有界分页与按回执精确回查，这属于后续运行详情/长任务验收缺口。完整 Console/Futures 逐页 UI、真实 DeepSeek 新执行器、P5 真实日期资料研究、P2 权限与旧部署退役仍在整体计划内。
