## 受控延迟浏览器回归

`node scripts/ui-race-fixture.mjs` 在回环端口 8109 提供真实 Console 构建所需的隔离 HTTP 夹具，不连接用户数据库、模型、凭证或外网。A 请求延迟 12 秒，B 延迟 20ms。构建 Web 后可重复以下手工场景：

1. Agent 列表依次点击 A、B；A 回来后标题、名称、唯一标识与提示词仍属于 B。实测通过。
2. 保存 B，立即切 ToolHub；保存回包后仍显示 Skill 目录，不重新打开编辑器。实测通过。
3. A 库发起检索后返回列表并打开 B，再检索 B；A 文件/检索回包晚到后仍只显示 B 的文件和证据。实测通过。
4. 留在 A 库等待 12 秒文件接口；列表显示 `A-only.txt`，不会被每五秒的新请求持续作废。实测通过。
5. ToolHub 检测弹窗先读 a.md、后读 b.md；12 秒后预览仍为 B。填 v1 审阅原因，点击夹具的重新检测按钮模拟目录新版本，下一轮目录刷新关闭旧弹窗；再打开 v2，原因、预览为空，启用按钮禁用。实测通过。首次等待 UI 隐藏的工具调用提前超时，随后目录实际刷新后状态符合预期；未将首次等待超时写成产品成功。

夹具仅验证页面异步状态，不代替 ToolHub 后台行为。真实 PostgreSQL 的 `TestHTTPBaselineEditPreservesBundleAndRequiresFreshApproval` 另外验证附件按指定旧版本复制、旧版不变、新版重新审批、无效基线/跨 ID/损坏附件拒绝。全量 Go 测试与 vet、Web 类型检查/双入口构建、四项 Web 渲染和资源详情测试通过。本轮没有重跑收费模型任务；之前的真实模型证据保留在交付账本。
