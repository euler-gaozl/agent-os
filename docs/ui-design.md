# Web 设计与验收

中台服务于资源管理和 Agent 调试；研序服务于提出研究问题、读取证据、回看资料。两者独立部署，不在业务界面暴露 Skill、MCP 或模型配置。

设计参考：Anthropic 官方 frontend-design skill 的明确视觉方向与实际渲染检查；shadcn/ui 的分组导航与表单结构；Manus 的任务输入与历史工作区。保留现有 React / TypeScript，使用本地系统字体和 SVG 图标，不加载第三方字体、图片或分析脚本。

- 中台采用浅灰工作区、白色内容面板、深墨色文字与青绿色操作强调。资源构建、运行维护、业务入口分组；刷新和异常反馈常驻可见。
- 内容文字 14px、辅助文字至少 12px；高密度表格保留可读性。卡片、表单和对话框使用一致的边框、圆角、焦点和间距。
- Agent 目录支持按本页发布状态筛选；编辑区左侧配置、右侧试运行。移动端按顺序排列并保留全部功能。
- 研序以研究问题为中心，范围和已选研究方式始终可见；历史可搜索，研究结果用适合长文和表格阅读的版式。
- 不用装饰性指标代替服务状态，不把进程在线当作真实能力验活；失败、等待核对和无结果分别呈现。
- 对话框锁定键盘焦点、Escape 关闭、关闭后恢复焦点；窄屏导航使用独立抽屉。尊重减少动画偏好。

验收覆盖中台六个页面、Agent 各配置页和试运行区、资源弹窗、知识库资料及检索、运行详情、研序首页和历史结果；使用桌面与 390px 窄屏逐页检查溢出、文字、焦点和空状态。截图保存在忽略的 `.state/ui-review/`，不提交个人业务数据。实施结果与限制另记入交付记录。
